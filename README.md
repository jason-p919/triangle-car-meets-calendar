# Triangle Car Meets Calendar

Public Apple Calendar–subscribable ICS for car meets in the Raleigh–Durham Triangle (NC).

**Calendar name:** Triangle Car Meets

## Subscribe (Apple Calendar / iOS)

1. Copy the **webcal** link below (preferred on Apple), or use the HTTPS raw URL.
2. On iPhone/iPad: Settings → Calendar → Accounts → Add Account → Other → Add Subscribed Calendar → paste the URL.
3. On Mac: Calendar → File → New Calendar Subscription… → paste the URL.
4. Set refresh to Weekly (or as preferred).

### Subscribe URLs

- **webcal (Apple):**  
  `webcal://raw.githubusercontent.com/jason-p919/triangle-car-meets-calendar/main/triangle-car-meets.ics`
- **HTTPS (raw ICS):**  
  `https://raw.githubusercontent.com/jason-p919/triangle-car-meets-calendar/main/triangle-car-meets.ics`

Google Calendar: Settings → Add calendar → From URL → paste the HTTPS raw URL.
